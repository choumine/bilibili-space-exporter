# B站视频批量提取器（Bilibili Space Exporter）

一个 Tampermonkey / Violentmonkey 用户脚本：自动提取 B 站用户空间（投稿视频）的全部视频信息，一键导出 CSV。

## 功能

- 打开 `space.bilibili.com/UID/video` 页面后自动识别 UID（支持数字 UID 与新版 ID 页面，识别失败时可手动输入）
- 通过 WBI 签名调用接口，按发布时间分页抓取全部投稿
- 导出字段（CSV，UTF-8 BOM 编码，Excel 直接打开不乱码）：
  - 标题 / BV 号 / 视频链接 / 发布时间 / 时长 / 播放量 / 弹幕数 / 评论数 / 简介
- 内置请求间隔（400–800ms 随机）与失败重试，尽量降低风控概率
- 对常见风控错误（-412 频率限制、-352 签名校验）给出明确提示

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey 扩展
2. 新建脚本，将 `bilibili-space-exporter.user.js` 的内容粘贴进去并保存；或直接把 `.user.js` 文件拖入浏览器按提示安装

## 使用

1. 打开目标用户的空间视频页，例如 `https://space.bilibili.com/22734073/video`
2. 页面右下角出现悬浮按钮，点击 → 「开始提取」
3. 等待进度完成，浏览器自动下载 CSV 文件

## 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 提示 -412 | 请求频率过高被风控。等待几分钟后重试，避免短时间内反复抓取大量视频 |
| 提示 -352 | WBI 签名校验失败。刷新页面后重试 |
| 无法识别 UID | 在弹窗中手动输入数字 UID（地址栏 `space.bilibili.com/` 后的一串数字） |
| 页数很多、抓取较慢 | 脚本按 400–800ms 随机间隔顺序抓取以避免触发风控，属正常现象 |
